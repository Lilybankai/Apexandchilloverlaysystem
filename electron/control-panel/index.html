                                LMU controls

                                The overlay can only press what LMU has bound to a key — a wheel button cannot be pressed from outside the game. This gives the missing ones a key, chosen from Japanese and Brazilian keys that do not exist on your keyboard, so nothing you (or OBS, or Discord) already use can ever clash with them.
                                Anything you have already bound is left exactly as it is.

                                Close Le Mans Ultimate first. The game rewrites its controls file from memory when it exits, so a change made while it is running is thrown away the next time you launch. A timestamped backup is taken before anything is written.

                                Bindings

                                Bind a key to any action. Bindings are global, so they fire while the sim has focus — and a Stream Deck button set to that key works too, since it just sends a keystroke.
                                Engineer Call … rows speak that fact over the radio with no microphone — last lap, sectors, gaps, fuel, track-limit points. Push-to-talk is still there for everything else.
                                There are no per-aid actions here: bind the four Pit menu ▲ ▼ + − controls and they reach every row the MFD shows, driving aids included.

                                A bound key is consumed — it will not also reach the sim. Pick keys LMU doesn't use.
