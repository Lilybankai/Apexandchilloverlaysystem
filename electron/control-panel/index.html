Adding an overlay to OBS

  1. In OBS, click + under Sources → Browser.
  2. Paste the overlay's URL (use Copy on the Overlays tab).
  3. Set width/height (e.g. 1920×1080), click OK.
  4. Drag the source where you want it over the sim.

    Bindings

    Bind a key to any action. Bindings are global, so they fire while the sim has focus — and a Stream Deck button set to that key works too, since it just sends a keystroke.
    Driving-aid actions come from LMU's own key bindings; rebind in game and they follow automatically.

    A bound key is consumed — it will not also reach the sim. Pick keys LMU doesn't use.
